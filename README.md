# Portfólio Lucas Ventura

Portfólio pessoal com apresentação, projetos, stack, trajetória e contato. Site estático em HTML, CSS e JS puro, sem framework.

## O que tem no site

Sobre, projetos publicados, stack principal, trajetória e links de contato. Layout com animações leves, partículas no hero e menu mobile.

## Tecnologias

HTML, CSS e JavaScript. Fontes Sora e Space Grotesk via Google Fonts.

Stack citada no conteúdo: Vue 3, Vuetify, TypeScript, Next.js, Node, PHP, Java e React Native.

## Como rodar

Só abrir o `index.html` no navegador. Ou subir um servidor local simples:

```
cd site-animado
python3 -m http.server 8000
```

Depois acesse http://localhost:8000
