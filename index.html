01 — Sobre

Transformo ideias em código que roda

Sou formado em Análise e Desenvolvimento de Sistemas e uso o GitHub como caderno de campo desde 2024. Comecei com Java e padrões de projeto na faculdade, passei por sites acadêmicos em HTML e CSS, e hoje construo aplicações completas: interfaces em Vue 3 e Next.js, APIs em Node e PHP. Gosto de front-end com atenção ao detalhe, mas não fujo do back-end — nem de infraestrutura, fila, cache ou rate limiting.
